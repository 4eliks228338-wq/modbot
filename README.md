# 🛡️ Discord User-App Moderation Bot

Универсальный бот-модератор, поддерживающий как классический режим работы на сервере, так и официальную функцию **User-Installed App** (установка прямо на личный аккаунт Discord).

> [!NOTE]
> **Главная фишка:** бот устанавливается на ваш личный аккаунт. Вы можете модерировать **абсолютно любой сервер**, на котором находитесь, **без необходимости приглашать бота на сам сервер**!

---

## 🚀 Как работает User App (на аккаунте пользователя)

В Discord появилась официальная функция **User Apps**. Добавив бота к себе в профиль:
1. Вы заходите на **любой сервер** (или в личные сообщения / групповой чат).
2. Нажимаете **правой кнопкой мыши** (или удерживаете пальцем на телефоне) по любому подозрительному сообщению.
3. Выбираете: **Приложения (Apps) ➔ 🛡️ Проверить сообщение**.
4. Бот мгновенно сканирует сообщение по всем правилам сервера (бан-ворды, трагедии, доксинг, реклама, спам и др.) и показывает вам карточку:
   - 🚨 Обнаруженные нарушения и точный триггер (слово/фраза).
   - 📊 Текущее количество варнов автора в базе данных.
   - ⚖️ Положенное наказание по шкале правил (таймаут 10м / 1ч / 1д / 1нед / 1мес или бан).
   - 🔗 Кнопка перехода к сообщению.
   - ⚠️ Кнопка **«Записать варн в базу»** — сохраняет варн нарушителю.
   - 📩 Кнопка **«Отправить алерт в ЛС»** — отправляет полную копию в ваши личные сообщения.
5. Также доступно контекстное меню пользователя: **ПКМ по участнику ➔ Приложения ➔ 📊 Варны пользователя** — просмотр истории варнов и кнопки `+1` / `-1` варн.

*(Если же бот также приглашён на сервер с правами администратора/модератора, он умеет делать всё это ещё и полностью автоматически в фоне через `on_message`, а также накладывать таймаут и удалять сообщения в 1 клик по кнопке).*

## 📋 Правила и фильтры модерации

1. **Бан-ворды и дискриминация:**
   - П-ворды (с учётом любых искажений, замены кириллицы на латиницу, цифр `1`, `0`, `3`, символов `@`, `$`).
   - Н-ворды (все формы расовых оскорблений).
   - Дискриминационные оскорбления по национальности, полу, ориентации, внешности, здоровью.
2. **Шутки про трагедии/драмы:**
   - Голда, коч, скулшутинг, колумбайн, керченский/казанский стрелок, Крокус и другие трагедии.
3. **Личная информация (Доксинг):**
   - Угрозы деанона, докса, сваттинга, пробива по базам данных, Глаз Бога.
   - Публикация телефонных номеров, IP-адресов.
4. **Реклама и сторонние приглашения:**
   - Ссылки на чужие Discord-сервера (`discord.gg/...`), каналы Telegram (`t.me/...`).
5. **Фишинг и скам:**
   - Мошеннические ссылки на фейковый Nitro, фейковые трейды Steam, вредоносные сайты.
6. **Угрозы и опасные действия:**
   - Прямые угрозы физической расправой, шантаж, призывы к насилию.
7. **Политика вне специального канала:**
   - Политические обсуждения разрешены только в канале с названием `🔴⟧дискуссии-не-самых-умных`.
8. **Спам и флуд:**
   - В канале `🚽⟧деревенский-туалет` флуд разрешён.
   - В остальных каналах отслеживаются: массовые пинги (`@everyone`, `@here`, 5+ упоминаний), зажатые клавиши (25+ одинаковых букв), капс (>75%), повторы одного текста.

## ⚖️ Шкала наказаний (Система варнов)

* **1 варн** — 10 минут таймаута
* **2 варн** — 1 час таймаута
* **3 варн** — 1 день таймаута
* **4 варн** — 1 неделя таймаута
* **5 варн** — 1 месяц таймаута *(в Discord API максимум 28 дней)*
* **6 варн** — бан на 1 месяц *(при повторном наборе 6 варнов — бан на 1 год)*

## ⚙️ Настройка и добавление бота на аккаунт

### Шаг 1: Создание приложения в Discord Developer Portal
1. Перейдите на [Discord Developer Portal](https://discord.com/developers/applications).
2. Нажмите **New Application**, введите название (например, `RuleGuard Mod`).
3. В меню слева перейдите во вкладку **Bot**:
   - Нажмите **Reset Token** и скопируйте полученный токен.
   - В разделе **Privileged Gateway Intents** включите галочки:
     - ✅ **Message Content Intent**
     - ✅ **Server Members Intent**

### Шаг 2: Включение функции User Install (установка на аккаунт)
1. В меню слева перейдите во вкладку **Installation**.
2. В блоке **Installation Contexts** поставьте галочки:
   - ✅ **User Install** *(главное! позволяет ставить бота на аккаунт)*
   - ✅ **Guild Install** *(позволяет при желании приглашать бота и на сервер)*
3. В блоке **Default Install Settings**:
   - В поле **Scopes** отметьте:
     - ✅ `applications.commands`
     - ✅ `bot`
   - В поле **Permissions** отметьте:
     - `Send Messages`, `Embed Links`, `Read Message History`, `Moderate Members`, `Manage Messages`.
4. В блоке **Install Link**:
   - Выберите: **Discord Provided Link**.
5. Нажмите зелёную кнопку **Save Changes** внизу.

### Шаг 3: Установка бота в свой профиль Discord
1. В том же окне скопируйте ссылку из поля **Install Link** и откройте её в браузере (или перейдите в профиль бота в Discord).
2. В появившемся окне Discord выберите:
   👉 **«Добавить в мой профиль» / «Установить для себя» (Install to Account / Try it now)**.
3. Нажмите **Авторизовать**. Готово! Теперь бот привязан к вашему аккаунту и доступен везде.

## 💻 Запуск бота

### 1. Настройка `.env`
В папке `/home/cross/Проекты/discord-mod-bot/` создайте или отредактируйте `.env`:
```ini
DISCORD_TOKEN=ваш_токен_бота
MODERATOR_USER_IDS=ваш_discord_id
```

### 2. Запуск
```bash
cd /home/cross/Проекты/discord-mod-bot
source venv/bin/activate
python bot.py
```

### 3. Фоновый запуск
```bash
cd /home/cross/Проекты/discord-mod-bot
nohup venv/bin/python bot.py > bot.log 2>&1 &
```

## 🕹️ Как пользоваться

* **Проверить сообщение в чате:**
  - Нажмите **ПКМ по сообщению** ➔ **Приложения** ➔ **`🛡️ Проверить сообщение`**.
* **Посмотреть варны участника:**
  - Нажмите **ПКМ по пользователю** ➔ **Приложения** ➔ **`📊 Варны пользователя`**.
* **Слэш-команды:**
  - `/warns @пользователь` — статистика варнов.
  - `/warn @пользователь [причина]` — записать варн нарушителю.
  - `/unwarn @пользователь` — снять один варн.
  - `/test_rules [текст]` — тестовая проверка текста на запрещённые слова.
  - `/help_mod` — справка по командам.
